## 已执行的实际工具检查

原生模块使用官方 MaaDeps v3.0.0、MaaFramework 5.14.3、OpenCV 4.12.0 与 AppleClang 21 完成生产 `cpp-algo` 全量编译链接，独立测试与 AddressSanitizer / UndefinedBehaviorSanitizer 检查通过。独立测试的控制器截图与定位使用替身，不代表游戏内导航已验收；此 macOS 环境未运行 LeakSanitizer。

人工任务已通过本地替身测试，覆盖控制命令、跨进程锁、暂停与停止、重启接续、损坏拒绝、单会话冻结及多会话离线输入；真实本机子进程检查了 SIGINT 和强杀后的恢复。CPython 启动安全、依赖锁、PowerShell 参数与准备锁释放通过本地检查。PowerShell 使用 macOS 上的 7.6.9 解析和模拟运行，不能替代 Windows PowerShell 5.1 或真实 SDK 任务验收。新增 `capture.plan/1.1` 保留未知位置和镜头意图，原 1.0 契约未放宽。

本工作区使用官方 COLMAP 4.2.1、OpenMVS 2.4.0 和已安装的 Blender。COLMAP / OpenMVS 下载、原始帮助输出、执行日志、自有多视角图片及所有检查脚本只保存在 `local/`。自制 Blender 场景已运行完整稀疏、稠密、网格和纹理处理；输出保持 `needs_review`，不自动宣布几何通过。

Blender 实际导出的 GLB / 三角碰撞发布包已交给网页校验器与 Chrome 加载，检查角色移动、画质切换及运行报告。分区、LOD、取消与恢复通过本地检查，不能据此宣称真实游戏世界或手机设备已验收。

## 已收到的 Windows 实机证据

2026-11-09 已收到用户的实际游戏报告与截图。正常 `doctor` 完成一帧，正常 `probe` 完成 12/12 帧，均记录为 2560×1440 原尺寸，工作进程已回收。正常 `probe` 报告列出的 29 个文件 SHA-256 全部匹配。

随后两轮在连接等待期间触发窗口条件拒绝，均为零帧并完成工作进程回收。第三轮尝试 11 次，其中第 1、6、7 帧成功，尺寸为 1920×1200，另外 8 次被窗口条件拒绝。第三轮采集报告为 `interrupted`，已有 `finished_utc` 与工作进程返回码。三轮异常采集报告共列出的 29 个文件 SHA-256 全部匹配。旧日志只使用失焦与最小化的共用拒绝文本，无法分别证明两种条件都已命中。

该中断轮的 PowerShell 外层报告已终结，但旧版 Python 依赖安装报告停留在 `installed`，缺少 `finished_utc`。现将安装报告限定为 `capture.probe.bootstrap/1.1` 的 `dependency_setup` 阶段，在启动探针前写完安装终态。PowerShell 外层继续汇总整个入口，采集结果由探针报告记录。新增窗口失败快照与状态布尔值已有本地回归，修复后的 Windows 表现尚未复测。

2026-11-09 用户明确要求跳过异常窗口状态测试并继续开发。该专项记为暂缓，已有的正常截图、窗口拒绝和中断记录仍保留，不把暂缓项标为通过，也不再用它阻塞后续独立开发。
